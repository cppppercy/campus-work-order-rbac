# 课堂演示步骤

初始演示账号密码均为 `Demo@12345`：`admin`、`manager`、`staff`、`viewer`。

1. 用 `viewer` 登录，进入工单管理。说明可查询，但新增、编辑、删除、分派、改状态、导出按钮禁用。
2. 用 `manager` 登录。说明可以分派普通用户；负责人列表不含 ADMIN，直接调用服务分派 ADMIN 也会被拒绝。
3. 用 `admin` 登录，在“角色与权限”选择 STAFF。权限按菜单、页面、操作分组显示；打开“配置权限”，授予 `workorder:delete`。
4. 用 `staff` 登录并刷新权限，删除按钮立即可用；回到 admin 撤销授权，再回到同一 staff 会话刷新，按钮变为不可用。
5. 用 admin 创建两个课程演示角色，例如 `SUPERVISOR` 与 `OPERATOR`；给 OPERATOR 授予一个操作权限。
6. 在 SUPERVISOR 的“配置继承”中勾选 OPERATOR。说明方向为“高级角色继承直属下级角色的有效权限”。将测试用户分配 SUPERVISOR 后刷新权限，展示继承效果。
7. 取消勾选 OPERATOR，保存并刷新测试用户权限，展示继承权限立刻消失；重启程序后再次查看，说明关系和撤销结果都已持久化。
